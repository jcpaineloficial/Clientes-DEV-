# Mila — Base de conhecimento silenciosa

A Mila ainda não está ativa no painel.

Esta pasta será atualizada toda vez que um módulo for aprovado. Quando a Mila for ativada, ela usará somente este conhecimento oficial, o perfil logado e as permissões reais do usuário.

A Mila não pode:

- consultar outra conta;
- revelar links ou códigos sem permissão;
- alterar créditos, clientes, permissões ou banco;
- executar comandos técnicos perigosos;
- inventar caminhos ou respostas.
