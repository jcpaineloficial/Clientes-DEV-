# Regra de entrega

Toda entrega deve informar:

- arquivos realmente alterados;
- módulo alterado;
- o que foi preservado;
- como testar;
- falhas conhecidas;
- status: desenvolvimento, revisão ou congelado;
- próximo passo.

Nunca chamar o painel inteiro de 100% quando somente um módulo foi alterado.
