Uso e atualizações

O tamanho dos repositórios é lido no GitHub. Nos projetos de download, o valor soma os arquivos da Release configurada.

Como usar

Os botões apenas levam você à área correta do GitHub. Para alterar arquivos, o GitHub solicitará a conta com permissão no repositório.
Painel e AutoatendimentoUse “Enviar atualização” para abrir a tela de upload da branch principal.
APKs, Mídias e ROMsUse “Editar Release” para adicionar, remover ou substituir os arquivos publicados.
Consumo mínimoSão no máximo cinco consultas públicas por hora neste navegador, sem atualização automática em segundo plano.
